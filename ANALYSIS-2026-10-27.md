## 2. Bugs found in today's log

### 2.1 News articles get credited to whichever target is scanned first  ⚠ correctness

`NewsScanner._seen_ids` (`orb_bot/news.py:111`) is **one set shared by every symbol**.
`fresh_signal()` marks an article as seen the first time *any* symbol scores it. When an
article is tagged with several tickers, whichever target the rescan loop reaches first claims
it, and every other target never sees it.

Today's log shows it:

| headline | paper credited to | live credited to |
|---|---|---|
| "Why Is IREN Stock Surging Tuesday?" | **CRWV** (+1.00, bias any → **long**) | **WULF** (+1.00) |
| "Why Is Applied Digital Stock Surging on Tuesday?" | CRWV | WULF |
| "Nvidia's Credit Risk Has Tripled…" | CRWV | CRWV (bias any → long) |

The same article landed on different symbols on the two instances, and a headline about IREN
set CRWV's trade direction. No trade was affected today, but it is order-dependent and
non-deterministic, and it can flip a bias.

**Fixed in f26338d**, with `test_news_dedup_is_per_symbol` in `tests/test_logic.py`. The
test replays this case and failed before the fix. The set is now keyed by
`(symbol, article_id)`, so each symbol scores an article independently:

```diff
-        self._seen_ids: set[str] = set()  # article ids already scored intraday
+        self._seen_ids: set[tuple[str, str]] = set()  # (symbol, article id) already scored
 ...
             for a in self._fetch(s, start):          # mark_seen
                 aid = str(getattr(a, "id", "") or getattr(a, "headline", ""))
                 if aid:
-                    self._seen_ids.add(aid)
+                    self._seen_ids.add((s, aid))
 ...
         for a in self._fetch(symbol, since):         # fresh_signal
             aid = str(getattr(a, "id", "") or getattr(a, "headline", ""))
-            if aid and aid in self._seen_ids:
+            if aid and (symbol, aid) in self._seen_ids:
                 continue
             if aid:
-                self._seen_ids.add(aid)
+                self._seen_ids.add((symbol, aid))
```

This makes attribution deterministic. It does **not** stop an IREN headline moving CRWV. It
makes it move CRWV on both instances. Relevance is a second, separate decision: only count
an article for a symbol if its ticker or company name appears in the headline.

## 3. The edge scan: what was tested and why it matters

**The question nobody had asked:** does the entry signal have drift? If it doesn't, no exit
rule can make money. Stops and trails reshape the distribution but cannot move its mean
(optional stopping). Every experiment since July (E5, E6, E10, E12, the trail work) assumed
there was drift to capture.

**The data:** `.sweep_cache/` already held 1-min bars for ~8,700 screened symbol-days
(2025-07 → 2026-08) that had only ever been used for parameter sweeps. `edge_scan.py`
turns them into signals in about 5 minutes.

| test | result |
|---|---|
| Q0: long breakout drift to 15:50 | **−0.206%** [−0.492, +0.077]; +5 min and +30 min significantly **negative** |
| live exit (stop 1.5 + trail 1.25) | −0.091% [−0.177, +0.000]: gross ≈ 0 |
| 4 other exit rules | −0.05% to −0.21%, all CIs span 0 |
| H-R: buy the downside break | FAIL: −0.15%, both periods negative |
| C1–C7: gap sign, first candle, VWAP, OR/ATR, timing, relvol proxy, breakout volume | **0 / 7 pass** |
| H-V: SIP opening relvol (the paper's own variable) | FAIL, and **inverted**: 4–8× relvol is −0.78% [−1.57, −0.07] |
| H-G: buy gap-downs ≤ −5% at the open (a different signal family) | FAIL: +0.15 discovery, −0.32 holdout. Deep gap-downs keep falling |

C5 (early breakout beats late) is the only split with the right sign in both periods
(+0.54 / +0.39), but its holdout CI spans zero. It doesn't pass, and it conflicts with E4.

### What it closes

- **Exit tuning as a source of edge.** The E12 paper trial can still run, since it's free,
  but its prior is now low. Expect ≈ 0.
- **The source paper's selection variable, inside this universe.** The screener already
  selects stocks in play (every name has gapped ≥ 2%). Extra opening volume inside that set
  marks exhaustion, not continuation.
- **"More trades"** (E9) for good: at zero gross edge, volume only adds cost.

### What it does NOT close

- ~~The short side.~~ **Checked, also ≈ 0.** Fading the upside break is the mirror of Q0:
  gross +0.106% to the close, about **+0.006% after the 0.10% round trip**, before borrow
  costs. Shorting the downside break (the mirror of H-R) is about −0.05% net. **Neither
  direction on either side of the range carries tradeable information on this universe.**
  The negative short-horizon drift is real but smaller than the spread.
- **Different universes.** This is the gap screener's universe. Large-cap or index ORB (the
  QQQ work, Track B) is a separate question.
- **Sub-minute effects.** IEX 1-min bars, as in every earlier test.

## 4. Recommendation

1. **Treat the live instance as what it measurably is: ≈ zero expectancy before costs.**
   It's small (a $450 cap, so about −$0.41 per trade net), and the expected cost is under a
   dollar a day. Whether to keep it running for
   the engineering and ops experience is Ethan's call. It shouldn't be kept on the
   expectation of profit.
2. **Adopt a drift-first gate for every new idea.** Before writing strategy code or a PREREG
   for an entry rule, add it as a `side` in `edge_scan._signal_row` and run Q0. If the drift
   isn't positive in both periods on 1,000+ signals, the idea dies in five minutes instead of
   five weeks. This is the most useful process change to come out of today.
3. **§2.1 (news attribution): done** in f26338d, its own commit with no other change in it.
   It's a correctness fix, not a strategy change, but it does alter behaviour on both
   instances: each target now sees every article tagged with it. Deploy it to both
   instances together, after the close, so they keep running the same code.
4. If the strategy work continues, change the **universe or the signal family**, not the
   parameters. Every opening-range variant on the gap-screened universe is now measured at
   ≈ 0 in both directions. Run any new candidate through the drift-first gate before it gets
   a PREREG.

## Literature checked today

- Zarattini, Barbon & Aziz (2024), *A Profitable Day Trading Strategy for the U.S. Equity
  Market*, SSRN 4729284. Still the source. **No independent out-of-sample replication found**
  since publication. QuantConnect's recreation (1,000-stock universe, Sharpe 2.4) is an
  in-sample backtest.
- Subhani (2026), *Opening-Range Breakouts on Event-Free Fridays: A Search-Aware Replication*,
  SSRN 7589980. 30-min ORB, 2018–2026. Reports effects concentrated in tech, growth and metals
  ETFs, and warns that results depend on the specification search, which is the same problem
  this project's 0-for-7 record documents.
- Notre Dame working paper (2025), end-of-day reversal. For **individual US stocks**,
  early-day returns *negatively* predict the last half hour in the cross-section. That is the
  opposite of the index-level intraday momentum of Gao, Han, Li & Zhou (2018), and it fits
  the negative drift measured here.
- Berkman, Koch, Tuttle & Zhang (2012): large overnight gaps tend to reverse intraday, more
  so in harder-to-arbitrage names. That fits C6/H-V, where the busiest gappers fade.
