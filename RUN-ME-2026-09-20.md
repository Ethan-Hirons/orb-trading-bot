## 3. The one test that matters — graceful shutdown

Do this **during market hours with a position open**. Any other time it
proves nothing, because there is nothing to flatten.

```bash
sudo systemctl stop orb-bot
journalctl -u orb-bot -n 40 --no-pager
```

Expect, in order:

```
SIGTERM received; finishing the current iteration, then flattening all positions before exit.
SHUTDOWN requested: flattening all positions before exit.
Flatten verified: no open positions.
Day done. Trades: N | End equity: ... | PnL: ...
```

Then confirm zero open positions in the Alpaca dashboard before you trust it.
Restart when you are done:

```bash
sudo systemctl start orb-bot
```

If the flatten ever hangs, sending the signal a second time exits immediately
and logs `exiting NOW without flattening` — then close by hand in Alpaca.
